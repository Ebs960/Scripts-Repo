# Religion Content Art Manifest

This manifest plans artwork only; it does not authorize placeholder images. Current icon status must be rechecked after running the content generator.

## Global style

Serious painterly game icons with one strong central symbol, moderate detail, strong silhouettes, and small-size readability. Icons must not be photorealistic or cartoonish and must contain **no text, UI frame, sprite sheet, collage, or incidental circular badge**. Export one icon per image on a true transparent RGBA background. God imagery should be formal, monumental, ritualized, and institutional; Spirit imagery should be natural, raw, animistic, and organic.
