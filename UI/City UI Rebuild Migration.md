# City Management drawer

The campaign scene uses `City UI Rebuild.prefab`. Its fixed city header and navigation remain visible while the five management sections share one vertical scroll view. The Citizens shortcut enters the existing tile assignment mode; the other shortcuts return to normal city inspection.

Production options still use the existing row prefab and city queue. The drawer shows current progress, estimated turns, and the next six queued items. Policies remain in Government because the current policy rules apply to civilizations, not cities.
